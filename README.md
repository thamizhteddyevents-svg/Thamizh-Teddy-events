# Thamizh Teddy Events

A Next.js starter website for the Thamizh Teddy Events project.

## Run locally
1. Install Node.js (LTS).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Important
This is the first frontend preview. The booking form currently shows a preview message only; it does not save bookings or send emails yet. Before public launch, connect a secure database, admin authentication, email provider, booking approval workflow, QR generation, and review/gallery management. Keep API keys in Netlify environment variables, never in frontend code.
